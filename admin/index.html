Доставка и подъём
Единые условия доставки для каталога. Для диванов можно добавить отдельную доплату за подъём.
Для дивана на сайте показывается базовая стоимость подъёма и дополнительная доплата за диван. Значение 0 отключает соответствующую доплату или порог бесплатной доставки.
